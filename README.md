# 💎 Çarşı Dekor

Kuyumcular için ölçüye özel **vitrin, banko, niş, yüzüklük ve manken** üreten **Çarşı Dekor** atölyesinin web sitesi. ✨

Ziyaretçiler yapılan işleri kategorilere göre inceleyebilir, telefon, WhatsApp veya iletişim formu üzerinden teklif isteyebilir. İşletme sahibi, yönetim paneliyle kategorileri, projeleri, fotoğrafları ve slider'ı kendisi yönetir.

## 🌟 Neler var?

- 🖼️ Slider'lı ana sayfa, kategori kutucukları ve öne çıkan işler
- 🗂️ İki seviyeli kategori menüsü ve fotoğraf galerisi
- 📞 İletişim formu, Google Haritalar, WhatsApp ve telefon butonları
- ❓ Sık sorulan sorular, gizlilik politikası, özel 404 ve teşekkür sayfaları
- 🔐 Şifreli yönetim paneli: kategoriler, projeler, slider, gelen mesajlar
- 🔎 Arama motorları için SEO düzenlemeleri (sitemap, paylaşım kartları, Google zengin içerik)
- 📱 Mobilde ekrana yapışık "Ara / WhatsApp" çubuğu

## 🛠️ Kullanılan teknolojiler

- ⚙️ ASP.NET Core Razor Pages
- 🗄️ Entity Framework Core + SQL Server
- 🎨 Bootstrap 5
